WEATHER TREND ANALYSIS ON AQI OF DIFFERENT CITIES IN INDIA

1. Introduction

This project focuses on analysing Air Quality Index (AQI) data of different cities in India using Python.

The project helps us understand air pollution levels, compare air quality between cities and identify trends in AQI.

2. Objectives

- To analyse AQI data of different Indian cities.
- To compare air quality between cities.
- To identify pollution trends.
- To study different air pollutants.
- To represent data through graphs and visualisations.

3. Tools and Technologies

- Python
- Pandas


4. Dataset Description

Dataset Name: enriched_aqi_dataset.csv

Total Records: 10,521

Total Columns: 22

The dataset contains information about cities, states, AQI levels, pollutants, temperature, humidity, wind speed and seasons.

5. Project Structure

- dataset: Stores the CSV dataset.
- Weather_Trend_Analysis.py: Contains Python source code.
- README.md: Contains project information.

6. Methodology

1. Import the dataset.
2. Explore the dataset.
3. Clean the data.
4. Perform data analysis.
5. Create graphs.
6. Interpret the results.

7. Expected Outcome

To understand AQI patterns and compare air quality across different Indian cities using Python data anlysis.

8. Conclusion

This project demonstrates the use of Python for analysing air quality data and understanding pollution trends in different cities of India.
